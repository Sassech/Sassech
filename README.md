## About me

I run infrastructure for a living and for fun. Most of my work lives in
reproducible Docker stacks: Mailcow, a private container registry, SonarQube,
n8n, Penpot, Postgres and MariaDB — deployed on Fedora and Ubuntu hosts,
fronted by Traefik and a Cloudflare Tunnel.

I also run a multi-arch K3s cluster (ARM64 VPS + AMD64 workstation) joined over
Tailscale, with WireGuard-encrypted pod networking and Ansible for provisioning.

- 🖥️ **Platform & DevOps**: Docker, K3s, Traefik, Cloudflare Tunnel, Ansible
- 🧱 Services in **Go**, **Rust**, **Python** and **Java / Spring**
- 🧪 I like deploys that are small, reproducible and boring
- 🌱 Going deeper into **distributed systems** and **system programming**
- 🎧 Off the clock: music, anime, and whatever the homelab demands
